关键判断规则

机会品

  • 先看成交表现是否较好。
  • 再看是否已报名价促场。
  • 高成交且未报名的商品，会列为机会品。
  • 通常按成交金额从高到低排序。

CPS 机会品

  • CPS 可以与其他价促场叠加。
  • 商品表现好但还没报 CPS 时，会列为 CPS 机会品。
  • 用于判断是否还有 CPS 增量空间。

秒杀质量

  • 爆发系数 ≥ 2.0：优质。
  • 爆发系数 ≥ 1.2：良好。
  • 爆发系数 < 1.2：低质。

超补质量

  • 转化率 ≥ 10%：优质。
  • 转化率 ≥ 5%：良好。
  • 转化率 < 5%：低质。
