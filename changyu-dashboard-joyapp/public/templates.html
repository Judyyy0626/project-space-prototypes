部署本地产物

上传本地 Agent 生成的资源包，或用 CLI 从本地一键部署。部署后可分享给指定人员查看。

点击选择或拖拽 zip 到此处 仅支持 zip 包，需包含 index.html 入口，单包 ≤ 50MB
未选择文件
部署后产物默认私有；分享链接做登录校验，页面内数据接口仍按访问人自身权限校验。

在本地 Agent 环境安装 CLI 后，一行命令把本地产物发布到平台：

# 1. 安装 CLI（示例占位）
npm i -g @jd/ai-space-cli

# 2. 登录
ai-space login

# 3. 在项目产物目录执行部署
ai-space deploy ./dist --name "营销场域看板0923"
CLI 部署完成后，产物会自动出现在「我的项目」列表，类型为「本地」。
