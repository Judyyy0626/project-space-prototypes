# 场域数据看板 · 想象力平台部署包

## 本地验证

```bash
npm start
```

打开：

```text
http://localhost:8080
```

## 页面结构

| 文件 | 说明 |
| --- | --- |
| `public/templates.html` | **核心页面** · 项目列表：我的项目管理（卡片/列表切换、来源/类型筛选、搜索）、新建项目（平台模板 / 部署本地产物）、模板卡片区、模板选择、阶段节点设置、成员选择 |
| `public/dashboard.html` | 价促场运营项目页：内嵌看板 iframe、标注模式、AI 助手对话、项目动态、自动化任务、知识库、技能库 |
| `public/dashboard-snapshot.html` | 看板数据快照（被 dashboard.html 内嵌），支持机会品重跑（需完整后端） |
| `public/index.html` | 入口跳转页，1.2s 后自动跳到 templates.html |
| `public/common.css` | 三个页面共享的设计变量、toast、抽屉、弹窗、按钮、徽章等公共样式 |
| `public/knowledge/` | 看板逻辑说明页与流程图 |
| `server.js` | 静态服务 + 机会品占位 API（`/api/opportunity/status`、`/api/opportunity/run`） |
| `_ssa_guard.js` | imagination-mcp 自动注入的 SSA 守卫，请勿手改 |

## 演示脚本

1. **项目列表**（templates.html）
   - 顶部搜索框：同时过滤「我的项目」和「如何创建项目」卡片区
   - 卡片 / 列表视图切换；来源（我创建的 / 我收到的）与类型（价促场 / 新品 / 本地）筛选
   - 项目卡片：重命名、删除（自定义确认弹窗）、固定到菜单（上限 3 个）
2. **新建项目 · 平台模板**
   - 「＋ 新建项目」→ 选「使用平台模板」→ 预览样板间（页内示例数据 + 模板信息）→ 使用模板 → 创建
3. **新建项目 · 新品**
   - 「＋ 新建项目」→ 选「部署本地产物」旁的入口（或模板卡片的「使用」）→ 填写新品信息 → 选推荐模板或手动创建阶段节点 → 选择成员（联系人 / 部门分组）→ 确认创建
4. **部署本地产物**
   - 上传 zip（支持拖拽）或查看 CLI 部署命令 → 部署后出现在「我的项目」，可在权限抽屉设置可见范围
5. **价促场运营项目页**（dashboard.html）
   - 数据看板内嵌 iframe + 「标注要修改内容」选区标注
   - AI 助手对话（starter 问题、任务草稿解析）
   - 自动化任务的开关、筛选、执行记录查看
6. **模板同步**（演示用）
   - templates.html 控制台执行 `openSyncDrawer()` 可查看模板更新同步检查抽屉（可自动同步 / 冲突项 / 高风险覆盖）

## 数据说明

- 项目列表数据存 `localStorage`（key：`changyuProjects`），刷新不丢；首次访问使用内置演示数据
- 任务、动态、技能等仍是内存数据，刷新还原（原型行为）
- 项目/任务操作输入均经过 `escapeHtml` 转义

## 部署要点

- 服务入口：`server.js`
- 静态资源：`public/`
- 监听端口：读取 `process.env.PORT`，默认 `8080`（SSA 守卫模式下内部端口 3001）
- 绑定地址：`0.0.0.0`
- 无额外依赖，无需 `npm install`
- 不使用本地持久化；当前看板是单文件静态快照
- 建议使用平台默认 SSO 守卫，不关闭 `withGuard`
